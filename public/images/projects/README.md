# Project images

Place project cover images and evidence screenshots in this directory.

Suggested naming:

- `salesforce-serverless-integration-cover.webp`
- `process-automation-platform-cover.webp`
- `melita-ai-agent-cover.webp`
- `italian-learning-saas-cover.webp`

Prefer WebP or AVIF, meaningful filenames, and optimized files. Add each path to
the corresponding `image` property in `src/content.ts`. Every image must keep a
descriptive `imageAlt`.
