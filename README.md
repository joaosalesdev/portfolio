# João Paulo — Portfolio

Portfolio profissional de **Software Engineering**, com foco em **Backend, Cloud, integrações e sistemas distribuídos**.

> APIs, arquiteturas serverless e automações aplicadas a problemas reais de negócio.

## Sobre o projeto

Este portfolio foi desenvolvido para apresentar minha trajetória, minhas competências técnicas e projetos de engenharia de software de forma clara e objetiva. Mais do que uma vitrine visual, cada projeto possui um estudo de caso que explica o problema de negócio, as decisões arquiteturais, o fluxo da solução, os desafios e os resultados alcançados.

A aplicação está disponível em português e inglês e foi construída com React, TypeScript e Vite.

## Principais destaques

- Interface responsiva e navegação em formato Single Page Application (SPA)
- Conteúdo completo em português e inglês
- Estudos de caso com contexto, responsabilidade, arquitetura e resultados
- Diagramas visuais criados como componentes React
- Projetos voltados a backend, AWS, IA, automação e produtos SaaS
- Publicação no GitHub Pages

## Projetos apresentados

| Projeto | Descrição | Principais tecnologias |
| --- | --- | --- |
| **Integração Salesforce** | Integração distribuída e orientada a eventos entre Salesforce e serviços AWS. | Python, AWS Lambda, API Gateway, SQS, Docker |
| **Melita AI Agent** | Agente de IA serverless para conversas contextualizadas e integração com LLMs. | Python, LangChain, AWS Lambda, Docker, CI/CD |
| **Plataforma de Automação de Processos** | Workflows em cloud para automação, integração e processamento de dados. | Python, EventBridge, Step Functions, Docker, RPA |
| **Plataforma SaaS de Ensino de Italiano** | Produto educacional com pagamentos, gamificação, APIs e recursos de IA. | PHP, JavaScript, MySQL, Stripe, REST API |

Cada projeto possui uma página própria com detalhes sobre o desafio, a solução, as decisões técnicas e as competências demonstradas.

## Tecnologias deste portfolio

- **React 19** para a construção da interface
- **TypeScript** para tipagem e manutenção segura do código
- **React Router** para navegação entre páginas e estudos de caso
- **Vite** para desenvolvimento e build
- **CSS** para layout responsivo, animações e identidade visual
- **GitHub Pages** para hospedagem

## Como executar localmente

### Pré-requisitos

- Node.js 20.19 ou superior
- npm

```bash
# Clone o repositório
git clone https://github.com/joaosalesdev/portfolio.git

# Entre no diretório
cd portfolio

# Instale as dependências
npm install

# Inicie o ambiente de desenvolvimento
npm run dev
```

Depois, acesse o endereço exibido pelo Vite no terminal.

## Scripts disponíveis

```bash
npm run dev      # Inicia o servidor de desenvolvimento
npm run build    # Gera a versão de produção
npm run lint     # Executa a análise estática do código
npm run preview  # Visualiza localmente o build de produção
```
